# Choosing a reliability safeguard for an enterprise answer workflow

Start with a real decision: what will someone do differently after reading this answer, and how reversible is that action? A false filing deadline can cost more than a referral. A needless referral on a common status question can erase the value of self-service. Measure each against a grounded baseline allowed to clarify or decline.

On Alder Desk, pre-checking 24 packets yielded 24 correct packet classifications, higher estimated operating cost and longer modeled latency. It passed the shared P4 attribution error. ## Candidate deployment patterns

These are engineering hypotheses. For each client, sample representative requests, label real failure causes, estimate traffic and harm by workflow, then shadow a candidate against the current system before changing what customers see.

| Architecture | When it earns consideration | Prerequisites, trade-offs and production signals | Adoption or rejection evidence |
|---|---|---|---|
| **Standard RAG** retrieves evidence and generates a cited answer, clarification or abstention. | Internal IT lookups, product support and reversible analyst queries with maintained sources. Weak fit for binding commitments without oversight. | Establish source owners, entitlements, versioning, retrieval monitoring and a clear fallback. One generation call. Audit unsupported claims and missing qualifiers, escalation rate, retrieval misses, p95 latency and cost per useful answer. | Keep it if a representative audit finds tolerable harm and checks mainly duplicate good abstentions. Reconsider if recurrent material errors remain despite adequate retrieval. |
| **Pre-generation gate** checks packet sufficiency and suppresses generation on BLOCK. | Support desks with frequent missing contract schedules or incomplete diligence files, provided a referral has a responsible recipient. Poor fit for predominantly supported lookups or errors introduced while writing. | Define packet-relative sufficiency, support for partial answers and clarification, immutable PASS forwarding and failure handling. Check cost on every query; generator spend saved only on blocks. Monitor useful answers lost, prevented errors, redundant blocks, referral backlog and serial latency. | Adopt if blocked cases contain costly errors the baseline really makes and prevented harm exceeds false-block cost. Reject if the baseline already requests missing documents or the gate mistakes ambiguity for insufficiency. |
| **Post-generation verifier** compares the actual candidate claims and citations to the packet before release. | Analysts quoting financial terms, diligence summaries and compliance guidance where a wrong number, actor or exception matters even with adequate evidence. Excessive for trivial reversible lookups if checks rarely change outcomes. | Need stable passage IDs, scoped authority rules, retention controls for the draft, a block fallback and independent audits of verifier misses. Always pay generator plus verifier. Monitor material errors caught, shared errors accepted, citation entailment, needless suppressions and tail latency. | Adopt when it catches consequential synthesis errors on adequate packets and the user can act on the referral. Reject when it repeats the generator's source mistake or discards many correct conditional answers. |
| **Selective verification** sends predefined high-risk requests to verification and serves the rest through standard RAG. Future option outside Phase B. | Mixed workloads, e.g. routine policy navigation alongside binding settlement terms. Insufficient where severity cannot be identified before serving the answer. | Predefine routing signals such as workflow, transaction type and consequence, then audit a random sample of bypassed traffic. Include routing cost, risk drift, missed high-severity cases and rollback. | Adopt only if routing captures enough costly errors out of sample while meeting latency targets. Reject if low coverage of risky cases or monitoring cost consumes the savings. |

**Fix the failure at its source.** When a signed amendment and a draft conflict, attach scope, status and effective dates during ingestion and enforce precedence. If signed peers conflict without resolution, refer to the document owner. If the governing document never reaches the packet, measure retrieval recall and repair indexing, access filters or ranking. A checker cannot recover an absent fact. For consequential writes, validate identity, permission, target and action direction in an execution control. Escalate unresolved ambiguity, exceptions requiring judgment and high-impact commitments to a named human with authority to decide. Log the evidence and final disposition.

## Illustrative economics for a client workshop

Use costs per 1,000 representative requests in the same period. Let **E** be material unsupported answers actually prevented relative to standard, **L** useful answers newly suppressed, and **H** additional human reviews. Expected net benefit is **E × expected loss per error − L × user cost per needless refusal − H × handling cost − incremental inference − latency cost − allocated operations cost**. Use severity-weighted loss including the probability that someone acts on the answer. Measure handling labor separately from user delay to avoid double counting. If the safeguard introduces new errors, deduct their expected losses.

For illustration only, suppose a prevented error avoids $40 in expected loss, eight needless refusals cost users $2 each, ten additional reviews cost $4 each, inference adds $1, latency adds $3 and monitoring adds $20 per 1,000. Added cost is $80. Two prevented errors break even; three yield $40 net under those assumptions. If expected loss is $10, eight preventions are needed to break even. A referral following an already correct abstention earns zero avoided loss. For a pre-gate subtract generator cost avoided on actual blocks; for a post-check charge verification on every candidate. Replace every assumption with client data and consider tail harm and mandatory controls independently of average dollars.
